End-to-End LLM Quantization & Serving Pipeline — Qwen3-4B

A full inference optimization pipeline taking Qwen3-4B from a standard HuggingFace model to a production-ready, quantized, high-throughput serving setup. The pipeline applies both GPTQ and AWQ quantization to INT4 precision, then serves the model via vLLM with speculative decoding using a Qwen3-0.6B draft model as the predictor.

The speculative decoding setup achieves a 1.7× decoding speedup by generating candidate token sequences with the smaller draft model, then verifying them in parallel with the target model, recovering most of the compute cost. End-to-end benchmarks cover p99 latency (under 560ms at 16 concurrent users), throughput scaling, and quality degradation, with a direct AWQ vs. GPTQ comparison across all three axes.

Multi-Agent LLM System for Collaborative Itinerary Planning

A LangGraph-based multi-agent system where 3–5 specialized agents autonomously negotiate conflicting travel constraints — budget vs. preferred airlines, layover tolerances, hotel tier — and produce conflict-free itineraries without human intervention in 87% of test cases.

The core is a ReAct-based orchestrator agent with live integrations to flight and hotel search APIs. A Streamlit frontend with human-in-the-loop checkpoints allows users to inspect and override agent decisions at any point in the planning process.

ASE Soft Failure Detection in Optical Networks via LSTM

Optical network soft failures : gradual OSNR degradations observed in optical networks as an effect of soft failures, are difficult to catch before they cause service degradation. Standard monitoring thresholds miss them because the signal still looks acceptable. The goal is to detect failure onset early, not just the final degraded state.

I use GNPy to simulate the failure: one amplifier out of 16 is selected at random and degraded over 25 rounds, with Noise Figure drifting via a Weibull distribution and Gain via a Gaussian : both progressively shifted rightward across rounds to mimic realistic worsening. Healthy amplifiers receive baseline noise additions so the problem doesn't become trivially easy by OSNR magnitude alone.

An LSTM trained on this temporal sequence learns to detect degraded paths and localize the failing amplifier via path intersection analysis across monitoring paths. Current results show 94.1% classification accuracy at ~5,000 simulation rounds. Localization accuracy recorded is 93.3 % for Top-3 candidate amplifiers and 81 % for Top-1.
